# Comprehension Questions: Robot Communication Concepts

## Test Your Understanding

Complete these questions to assess your understanding of the robotic nervous system concepts covered in this module. These questions will help reinforce the key concepts and identify areas where you might need additional review.

## Section 1: Basic Concepts

### Question 1: Robot Functions (Nodes)
**What is the best analogy for a robot "node"?**

A) A cable connecting two computers
B) A specialized department in a company
C) A radio station broadcasting to listeners
D) A customer service representative

*Hint: Think about how different parts of a robot specialize in specific tasks.*

### Question 2: Information Sharing (Topics)
**Which communication type is best suited for sharing sensor data that multiple robot functions need to access?**

A) Services
B) Actions
C) Topics
D) Parameters

*Hint: Consider which communication type allows one sender to broadcast to multiple receivers.*

### Question 3: Formal Requests (Services)
**When would a robot use a "service" communication pattern?**

A) Broadcasting location information to all functions
B) Requesting a specific calculation with a guaranteed response
C) Performing a long-term navigation task
D) Continuously monitoring sensor data

*Hint: Think about direct request-response interactions.*

## Section 2: Communication Patterns

### Question 4: Communication Comparison
**Match each communication type to its primary characteristic:**

1. Topic
2. Service
3. Action

a) Request-response pattern with blocking behavior
b) Continuous broadcast to multiple subscribers
c) Long-running operation with feedback

### Question 5: Real-World Application
**A robot needs to calculate the shortest path between two points. Which communication type should it use and why?**

A) Topic - because path information should be broadcast continuously
B) Service - because it needs a specific calculation with a guaranteed response
C) Action - because path planning takes a long time
D) None of the above

### Question 6: Analogy Application
**In the company department analogy, which scenario best represents "topic" communication?**

A) HR requesting employee information from Payroll
B) A manager assigning a project to a team member
C) A company-wide announcement posted on the bulletin board
D) Customer calling customer service for support

## Section 3: Software-to-Action Connection

### Question 7: Decision Pipeline
**What is the correct order of the decision pipeline from perception to action?**

A) Physical action → Decision → Processing → Perception
B) Perception → Processing → Decision → Physical action
C) Decision → Perception → Physical action → Processing
D) Processing → Perception → Decision → Physical action

### Question 8: Component Mapping
**Which of the following correctly maps a human body part to its robot equivalent?**

A) Eyes : Motors
B) Brain : Cameras
C) Nerves : Network connections
D) Muscles : Sensors

## Section 4: Application Scenarios

### Question 9: Scenario Analysis
**A delivery robot needs to navigate through a crowded hallway. Place these steps in the correct order:**

A) Motor control software sends commands to wheel motors
B) Navigation software calculates a safe path around people
C) Camera and proximity sensors detect people in the hallway
D) Robot physically moves through the hallway

### Question 10: Problem Solving
**Why might a robot use different communication types (topics, services, actions) instead of just one type for everything?**

A) It makes the robot more expensive
B) Different types are better suited for different kinds of interactions
C) It's required by law
D) It makes the robot slower

## Answer Key

### Section 1 Answers:
1. B) A specialized department in a company
2. C) Topics
3. B) Requesting a specific calculation with a guaranteed response

### Section 2 Answers:
4. 1-b, 2-a, 3-c
5. B) Service - because it needs a specific calculation with a guaranteed response
6. C) A company-wide announcement posted on the bulletin board

### Section 3 Answers:
7. B) Perception → Processing → Decision → Physical action
8. C) Nerves : Network connections

### Section 4 Answers:
9. C → B → A → D (Perception → Decision → Command → Action)
10. B) Different types are better suited for different kinds of interactions
