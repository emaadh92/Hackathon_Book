# Data Model: Book Website Embeddings Pipeline

## Entities

### DocusaurusPage
Represents a crawled page from a Docusaurus site

**Fields**:
- `url`: str (primary identifier, unique)
- `title`: str (page title from HTML)
- `content`: str (clean text content extracted from page)
- `html_content`: str (raw HTML content, optional)
- `last_modified`: datetime (timestamp of last crawl)
- `status_code`: int (HTTP status code from crawl)
- `error_message`: str (error details if crawl failed, optional)

**Validation Rules**:
- `url` must be a valid URL format
- `content` must not be empty when status is successful
- `url` must be unique per crawl session

### TextChunk
Represents a segment of text prepared for embedding

**Fields**:
- `chunk_id`: str (unique identifier for the chunk)
- `original_url`: str (reference to source page)
- `content`: str (text content for embedding)
- `start_pos`: int (starting character position in original content)
- `end_pos`: int (ending character position in original content)
- `section_title`: str (title of section this chunk belongs to, optional)
- `chunk_metadata`: dict (additional metadata for the chunk)

**Validation Rules**:
- `content` length must be within Cohere's token limits
- `chunk_id` must be unique across all chunks
- `original_url` must reference an existing DocusaurusPage

### EmbeddingVector
Represents a semantic vector generated by Cohere

**Fields**:
- `vector_id`: str (Qdrant point ID)
- `chunk_id`: str (reference to source TextChunk)
- `embedding`: list[float] (vector values from Cohere)
- `size`: int (dimension of the embedding vector)
- `created_at`: datetime (timestamp of embedding generation)

**Validation Rules**:
- `embedding` must have consistent dimensions
- `vector_id` must be unique in Qdrant collection
- `size` must match the expected embedding dimension for the model used

### StorageRecord
Represents the stored entry in Qdrant with metadata

**Fields**:
- `qdrant_point_id`: str (Qdrant unique identifier)
- `payload`: dict (metadata stored with the vector)
  - `url`: str (source URL)
  - `chunk_id`: str (reference to TextChunk)
  - `content`: str (the text that was embedded)
  - `section_title`: str (optional section title)
  - `source_type`: str (type of source document)
  - `created_at`: datetime (storage timestamp)
- `vector`: list[float] (the embedding vector)

**Validation Rules**:
- `qdrant_point_id` must be unique in the collection
- `payload` must contain required metadata fields
- `vector` must match expected dimensionality

## Relationships

```
DocusaurusPage (1) → (Many) TextChunk
TextChunk (1) → (1) EmbeddingVector
EmbeddingVector (1) → (1) StorageRecord
```

## State Transitions

### DocusaurusPage States
- `PENDING` → `CRAWLING` → `SUCCESS`/`FAILED`
- `SUCCESS` → `PROCESSED` (after embedding)

### TextChunk States
- `CREATED` → `EMBEDDING` → `EMBEDDED`/`FAILED`

## Collection Schema (Qdrant)

### Vectors Collection
- **Collection name**: `book_embeddings`
- **Vector size**: 1024 (for Cohere multilingual v3)
- **Distance metric**: Cosine
- **Additional payload indexes**:
  - `url` (keyword index)
  - `section_title` (keyword index)
  - `created_at` (integer index)
